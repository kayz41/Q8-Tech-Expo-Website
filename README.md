# Question 08 — Uganda International Coffee Expo Website

A multi-page event website practical for a fictional Uganda International Coffee Expo.

## Files
- `index.html` — event homepage
- `programme.html` — three-day programme
- `speakers.html` — speaker profiles
- `exhibitors.html` — exhibitor placeholder page
- `expo.css` — shared external stylesheet

## Asset note
The source pages reference `expo-banner.jpg` and speaker photographs. These image files are absent from the original Question-08 folder and have not been fabricated. Add approved assets when available.

## Run locally
Open `index.html` in a browser and use the navigation links to explore the other pages.
